## Разработка конфигурации «Учёт материалов» на платформе 1С:Предприятие 8.3
*Учебный проект, 2024–2026 гг.*

**Описание:** Проектирование и реализация конфигурации с нуля в режиме управляемого приложения для автоматизации складского учёта. Разработка модульной структуры из 4 подсистем, создание объектов метаданных (справочники, документы, регистры накопления). Реализация клиент-серверной логики с директивами `&НаКлиенте`/`&НаСервере`, программное проведение документов с контролем остатков через запросы к виртуальным таблицам. Настройка СКД (Системы Компоновки Данных) для формирования аналитических отчётов по движению материалов. Тестирование интеграции модулей, отладка кода и настройка прав доступа по ролям.

**Что сделано:**
- Архитектура и метаданные: 4 подсистемы, иерархические справочники, документы поступления/списания
- Программная логика: клиент-серверное взаимодействие, процедуры проведения с контролем остатков
- Отчётность: СКД-отчёты с параметрами периода и группировкой по номенклатуре
- Интерфейс: командный интерфейс, роли пользователей, валидация реквизитов

**Стек:** 1С:Предприятие 8.3, управляемое приложение, язык запросов 1С, СКД, клиент-серверная архитектура
**Направление:** Разработчик 1С, Системный аналитик
